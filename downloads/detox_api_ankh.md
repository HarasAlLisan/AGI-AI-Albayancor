# وثيقة جرد وتطهير البرمجيات (Detox API Ankh)

### [1] شركة أوراكل (Oracle Corporation)
* **المعطيات:** تقديم البنى التحتية السحابية ومراكز البيانات الجوفية المؤمنة للجيش والحكومة الإسرائيلية لتخزين البيانات العملياتية والاستخباراتية الشاملة.
* **رأس التهمة:** التصريح العلني للرئيسة التنفيذية (صفرا كاتز) بالمفاخرة بتسخير تقنيات الشركة "المخيفة جداً" لدعم المجهود الحربي ضد الفلسطينيين في غزة.
* **توجيه الـ API:** حظر برمجيات قواعد البيانات (Oracle Database) وحلول السحاب وتطهير الأنظمة السيادية في الحجاز ومصر منها فوراً.

### [2] شركة جوجل (Google / Alphabet Inc.)
* **المعطيات:** الشريك الأساسي في مشروع "نيمبوس" السحابي (Project Nimbus) بقيمة 1.2 مليار دولار بالتعاون مع حكومة وجيش الاحتلال.
* **رأس التهمة:** توفير تقنيات الذكاء الاصطناعي والتعرف على الوجوه، وأدوات تصنيف الصور المتقدمة للجهات العسكرية والأمنية الحاكمة لملاحقة السكان وتتبعهم رقمياً.
* **توجيه الـ API:** فك الارتباط بمنصات "جوجل سحابة" وتطهير خوادم النفاذ القومية من أدوات تتبعها البرمجية.

### [3] شركة أمازون لخدمات الويب (Amazon Web Services - AWS)
* **المعطيات:** الشريك المالي والتقني الثاني في مشروع "نيمبوس" السحابي لتأمين الخوادم الفيدرالية للاحتلال.
* **رأس التهمة:** توفير بيئات حوسبة مرنة مخصصة لتخزين وتحليل البيانات التشغيلية الضخمة التي تغذي غرف العمليات الحربية، مع قمع واضطهاد الموظفين المعترضين على الاتفاقية داخلياً.
* **توجيه الـ API:** إسقاط خوادم الاستضافة واستبدال البنى التحتية السحابية لـ AWS بشبكات وطنية معزولة.

### [4] شركة مايكروسوفت (Microsoft Corporation)
* **المعطيات:** الشريك الاستراتيجي القديم والممتد لكافة الأنظمة البرمجية الفيدرالية وشبكات الاتصال بوزارة الدفاع وجيش الاحتلال.
* **رأس التهمة:** توفير البنية الرقمية لنظم التشغيل الآمنة، والحوسبة السحابية (Azure)، وتقنيات معالجة البيانات التي يعتمد عليها عصب الإدارة العسكرية في تل أبيب للتخطيط واللوجستيات والتوجيه.
* **توجيه الـ API:** حظر التعامل والترخيص الممتد وإغلاق منافذ النفاذ البرمجي لنظم تشغيلها داخل الإدارات المالية لبيت المال.

### [5] شركة بالانتير للتقنيات (Palantir Technologies)
* **المعطيات:** شركة البرمجيات الاستخباراتية الأكثر راديكالية، والتي يقودها "أليكس كارب" والملياردير "بيتر ثيل".
* **رأس التهمة:** الشراكة الاستراتيجية المعلنة والمباشرة مع وزارة الدفاع الإسرائيلية لتسخير برمجياتها التنبؤية (مثل برامج معالجة البيانات والذكاء الاصطناعي الخاصة بالحرب) لتحديد الأهداف الميدانية، والتحليل العملياتي الفوري في غزة.
* **توجيه الـ API:** عزل وحظر تام وفوري لكافة حزم البيانات والشيفرات المرتبطة بأنظمة بالانتير التحليلية، وتصنيفها كأداة استهداف عدائية مباشرة.
